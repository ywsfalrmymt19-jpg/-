### للمؤلف: د. مالك عبدالرحمن الرميمة

تطبيق أندرويد تفاعلي وناطق فائق الدقة مبني بأحدث تقنيات أندرويد الحديثة (**Jetpack Compose** و **Material 3**) ومتوافق تماماً مع **Android 15**.

## ✨ أهم مميزات التطبيق

1. **التفريغ النصي الكامل والتطابق التام (18 صفحة وفصل):**
   - صفحة الغلاف والملخص العام.
   - صفحة الإهداء.
   - الفهرس التفصيلي لجميع المباحث.
   - كافة المباحث والفصول الـ 14 كاملة مع شواهد القرآن والسنة.
   - الخاتمة والتوثيق النهائي.

2. **القارئ الصوتي التفاعلي (Arabic Text-to-Speech):**
   - استماع صوتي باللغة العربية الواضحة لكل صفحة.
   - شريط تحكم عائم (تشغيل/إيقاف، التنقل بين الصفحات، وتعديل السرعة من `0.75x` حتى `1.5x`).

3. **أنماط قراءة مريحة للعين (5 سمات):**
   - **الورقي الدافئ (Paper):** مظهر المخطوطات والكتب المطبوعة.
   - **الأبيض الناصع (Light):** قراءة ساطعة ومريحة نهاراً.
   - **السيبيا الكلاسيكي (Sepia):** لراحة العين وتقليل الإجهاد.
   - **الليلي الهادئ (Dark):** وضع داكن هادئ.
   - **الأسود الحالك (AMOLED):** توفير طاقة البطارية للشاشات الحديثة.

4. **البحث السريع والفهرس التفاعلي:**
   - محرك بحث نصي فوري في جميع صفحات الكتاب مع إبراز النتائج.
   - فهرس سريع وانتقال عبر شريط الصفحات السفلي.

5. **الإشارات المرجعية والملاحظات الشخصية:**
   - حفظ أي صفحة وإضافة ملاحظات شخصية عليها مع حفظ دائم على الذاكرة المحلية.

6. **تخصيص القراءة:**
   - تكبير وتصغير حجم الخط (من 14 إلى 32 نقطة).
   - إمكانية التبديل بين نمط الصفحات المنفصلة (Pager) والتمرير المستمر (Scroll).
   - خيار إبقاء الشاشة مضاءة أثناء القراءة.

## 🛠️ أسرار ومفاتيح GitHub Secrets المستخدمة في البناء

تم إعداد ملف سير العمل (`.github/workflows/build_apk.yml`) ليقوم بقراءة المفاتيح السرية التالية تلقائياً من إعدادات مستودعك:

| اسم المفتاح السري (Secret Name) | الغرض منه في البناء |
| :--- | :--- |
| `KEYSTORE_BASE64` | ملف شهادة توقيع التطبيق مشفر بنظام Base64 لإنتاج ملف APK موقع وموثوق |
| `CM_KEYSTORE_PASSWORD` | كلمة مرور ملف الـ Keystore |
| `CM_KEY_ALIAS` | الاسم المستعار للمفتاح (Key Alias) |
| `CM_KEY_PASSWORD` | كلمة مرور المفتاح الخاص |
| `GEMINI_API_KEY` | مفتاح واجهة الذكاء الاصطناعي من Google AI Studio |

## 🚀 كيفية تشغيل البناء الآلي (GitHub Actions) وتنزيل ملف الـ APK

بمجرد دفع هذا المشروع إلى مستودعك على GitHub:

1. **بدء البناء التلقائي:**
   - سيبدأ سير العمل **"Build Android APK"** بالعمل تلقائياً فور الـ `push`.
   - أو يمكنك الدخول إلى تبويب **Actions** في صفحة مستودعك، واختيار **Build Android APK** ثم الضغط على زر **Run workflow**.

2. **الحصول على رابط تثبيت الـ APK:**
   - عند اكتمال البناء (ستظهر علامة الصح الخضراء ✅):
     - **الطريقة الأولى (GitHub Releases):** ادخل إلى قسم **Releases** على يمين صفحة المستودع وستجد ملف الـ APK جاهزاً للتحميل المباشر بنقرة واحدة.
     - **الطريقة الثانية (Artifacts):** في صفحة الـ Workflow المكتملة، انزل لأسفل إلى بند **Artifacts** وحمل حزمة `IslamicPeoplesOppression-APK`.

3. **تثبيت التطبيق على هاتفك (Android 15 والأجهزة السابقة):**
   - افتح ملف الـ APK على هاتفك واضغط **تثبيت (Install)**.
   - سيعمل التطبيق فوراً بدون الحاجة لأي إنترنت مع دعم كامل لكافة الميزات الصوتية والنصية.
